1. Purpose

The Islands Rug Spa is a small, local service business that advertises on Google Search to reach homeowners looking for rug and upholstery cleaning. Islands Ads Manager is a private command-line tool that lets the owner report on, adjust and grow these Search campaigns more efficiently than the web interface alone allows. The tool is not a product, is not sold or offered to third parties, and does not manage accounts belonging to any other advertiser.

Goals

  • Pull daily performance reports (spend, clicks, calls, leads, cost per lead) by campaign, city and keyword.
  • Make routine changes in bulk: adjust budgets, pause or enable campaigns and ad groups, add negative keywords.
  • Build new geo-targeted Search campaigns for each service area. Each one points to the city landing pages already on the website.
  • Make scaling decisions: shift budget toward the cities and keywords with the lowest cost per lead.

2. Users and access

  • Users: the business owner only (one or two people within the company). No external users and no client accounts.
  • Authentication: OAuth 2.0 (Desktop app client) as the business's own Google account, with the https://www.googleapis.com/auth/adwords scope. Calls go through the manager account 891-412-2258 using login-customer-id.
  • Credential storage: the developer token, OAuth client secret and refresh token are stored in a local configuration file with owner-only file permissions. They are excluded from source control and never deployed to a server or the website.

Reports can be saved locally as CSV files for review. Write operations (budget, status, keyword and campaign changes) show a preview of the change and require confirmation before they are sent to the API. The tool calls the API only when the owner runs a command. A scheduled daily report may run at most once per day.

4. Google Ads API usage

ServiceUse
CustomerServiceList the accounts the user can access (connection check).
GoogleAdsService (Search / SearchStream)GAQL reporting on customer, campaign, ad_group, keyword_view, search_term_view, geographic_view and conversion metrics.
CampaignBudgetServiceCreate campaign budgets and change their amounts.
CampaignServiceCreate Search campaigns; pause or enable them; set the bidding strategy.
CampaignCriterionServiceLocation targeting (Charleston-area cities and ZIP codes) and campaign-level negative keywords.
AdGroupService / AdGroupCriterionServiceCreate ad groups; add, pause and change bids on keywords.
AdGroupAdServiceCreate and pause responsive search ads.
AssetService / CampaignAssetServiceCall, sitelink and callout assets.
ConversionActionServiceRead and set up conversion actions for phone calls and booking requests.

Expected volume: one advertiser account with roughly 5–15 campaigns. Expect a few hundred operations per day at most, well within Basic access limits.

6. Compliance

  • Only accounts owned by The Islands Rug Spa are accessed. The tool is never offered to other advertisers.
  • Google Ads data stays on the owner's machine and is not shared with or sold to any third party.
  • The tool follows the Google Ads API Terms and Conditions, the Required Minimum Functionality rules where they apply, and the rate limits. Failed requests are retried with exponential backoff.
  • API errors and request IDs are logged locally for troubleshooting.
